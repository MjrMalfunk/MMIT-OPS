# eSignatures.com live template field map

Use these OPS merge field names exactly in the eSignatures.com provider template. The provider placeholder syntax should be `{{placeholder_name}}`.

| OPS merge field | Provider placeholder | Live template location |
| --- | --- | --- |
| `contract_number` | `{{contract_number}}` | Order Form Summary contract number. |
| `contract_title` | `{{contract_title}}` | Order Form Summary contract title. |
| `client_name` | `{{client_name}}` | Order Form Summary client and client signature section authorized signer. |
| `company_name` | `{{company_name}}` | Order Form Summary company and client signature section company. |
| `primary_contact` | `{{primary_contact}}` | Order Form Summary primary contact. |
| `contact_email` | `{{contact_email}}` | Order Form Summary contact email and client signature section signer email. |
| `service_plan` | `{{service_plan}}` | Order Form Summary and Service Schedule selected plan. |
| `productivity_platform` | `{{productivity_platform}}` | Order Form Summary and Service Schedule platform. |
| `license_level` | `{{license_level}}` | Order Form Summary and Service Schedule license level. |
| `billing_cycle` | `{{billing_cycle}}` | Order Form Summary and Service Schedule billing cycle. |
| `recurring_total` | `{{recurring_total}}` | Main agreement total labeled “Recurring total for selected billing cycle.” |
| `covered_workstations` | `{{covered_workstations}}` | Order Form Summary and Service Schedule covered environment. |
| `covered_users` | `{{covered_users}}` | Order Form Summary and Service Schedule covered environment. |
| `covered_servers` | `{{covered_servers}}` | Order Form Summary and Service Schedule covered environment. |

| `monthly_amount` | `{{monthly_amount}}` | Legacy/backward-compatible placeholder only; do not use as the live template's primary displayed total. |
