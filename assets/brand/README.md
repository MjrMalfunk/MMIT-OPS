# Midwest Managed IT — SVG Brand Pack

## Included files
- `mmit-icon.svg` — icon only, transparent background
- `mmit-icon-dark.svg` — icon only on dark background
- `mmit-icon-light.svg` — icon only on white background
- `mmit-icon-monochrome-dark.svg` — white monochrome icon on dark background
- `mmit-icon-monochrome-light.svg` — dark monochrome icon on white background
- `mmit-logo-stacked-dark.svg` — primary stacked logo on dark background
- `mmit-logo-stacked-light.svg` — primary stacked logo on white background
- `mmit-logo-horizontal-dark.svg` — horizontal logo on dark background
- `mmit-logo-horizontal-light.svg` — horizontal logo on white background
- `mmit-favicon-512.png` — app/store sized icon
- `mmit-favicon-64.png` — quick web icon
- `mmit-favicon.ico` — browser favicon

## Brand colors
- Blue: `#2563EB`
- Purple: `#7C3AED`
- Dark background: `#0F172A`
- Light text: `#F9FAFB`
- Secondary gray: `#94A3B8`

## Recommended usage
- Website hero / launch page: stacked dark
- Invoices / documents: horizontal light
- Syncro / portal icon: icon only
- Email signatures: horizontal light or horizontal dark depending on background
- Favicon: `.ico`

## Font pairing
- Preferred: Inter
- Backup: Arial, sans-serif
